# GinishTech-People-Insights-Dashboard
A strategic People Analytics solution built in Power BI to monitor workforce stability, analyze compensation distribution, and provide actionable talent retention insights.

# People Insights Dashboard

![People Insights Dashboard](GinishTech%20Screenshot.png)

## Project Overview
This repository contains a comprehensive Human Resources analytics solution built in Power BI. The dashboard investigates employee demographic trends, salary distributions, and key drivers behind workforce attrition.

## Dataset
* **Source File:** `GinishTech People Insights Excel.csv`
* **Size:** 1,480 employee records across 37 data columns (including Age, Department, Income, and Attrition status).

## Key Insights & Features
* **Attrition Analysis:** Highlighting flight risks based on department, job role, and work-life balance.
* **Compensation Metrics:** Evaluating salary slabs and performance ratings to ensure internal equity.
* **Interactive UI:** Dynamic filtering by Age Group, Gender, and Department.

## How to View the Dashboard
1. Download the `GINISHTECH PowerBI Dashboard.pbix` file from this repository.
